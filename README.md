# Workspace — корпоративная база знаний и командная работа

> **Самостоятельно хостимая платформа** упрощенный клон Notion с блочным редактором, чатом, видеозвонками и полным контролем над данными.

Workspace — это единое рабочее пространство для вашей команды, где можно создавать документы, общаться в реальном времени, делиться файлами и проводить видеовстречи — всё в одном месте и без привязки к сторонним сервисам.

---

## 🚀 Возможности

### 📄 Блочный редактор
- Пишите статьи, заметки, техническую документацию с помощью **/‑команд** и **инлайн-форматирования** (жирный, курсив, код, ссылки).
- Вставляйте **изображения, файлы, таблицы, чек‑листы, код** и многое другое.
- Перетаскивайте блоки мышью, удаляйте по одному — редактирование интуитивно понятно.
- Вставляйте текст из буфера — структура и форматирование сохраняются.

### 👥 Командная работа
- **Жёсткое разграничение прав** (Read / Comment / Edit / Admin) на каждый документ.
- Делитесь страницами с коллегами или открывайте публичный доступ по ссылке.
- **Комментарии** под каждой статьёй — плоский список с реакциями-эмодзи, редактированием и удалением.
- **Присутствие (presence)** — видите, кто сейчас просматривает страницу, с аватарами.

### 💬 Чат и видеозвонки
- **Личные и групповые чаты** с живой доставкой сообщений и индикатором «печатает…».
- **Треды** для обсуждения отдельных сообщений.
- **Видеозвонки** (до 8 участников, mesh‑топология) с демонстрацией экрана — свой STUN/TURN, никаких внешних провайдеров.
- Вложения, ссылки на страницы (с проверкой доступа), Markdown и реакции.

### 🔒 Безопасность и приватность
- Все данные хранятся на **вашем сервере** — никаких облачных провайдеров.
- **JWT‑аутентификация** и **RBAC** (Admin, Team‑Lead, Member, Guest).
- Самостоятельная регистрация отключена — только приглашения от администратора.
- Встроенная **санитизация** HTML и защита от path traversal.

### 🎨 Кастомизация
- **Брендирование** под свой цвет и логотип — настройки сайта, аватары пользователей.
- **Тёмная/светлая тема** (автоматически под систему).
- **PWA** — устанавливается как приложение на рабочий стол (Chrome/Edge/Brave).

### 🗂️ Организация контента
- **Личное дерево страниц** и **отдельное файловое хранилище** для каждого пользователя.
- **Расшаренные страницы** отображаются в том же сайдбаре.
- **Публичные страницы** — курируемое дерево документов, доступное без входа.
- **Оглавление, теги, связанные документы** — автоматически строятся из содержимого.

### 👤 Администрирование
- **Админ‑панель** (`/admin`) — создание/редактирование/удаление пользователей, сброс пароля, приглашения по ссылке.
- Управление публичными страницами и заявками на публикацию.
- Настройки сайта (название, описание, копирайт, логотип).

## ⚡ Быстрый старт

1. Убедитесь, что установлены **Node.js (18+)** и **npm**.
2. Клонируйте репозиторий и установите зависимости:
   ```bash
   npm install
   ```
3. Скопируйте .env.example в .env и настройте переменные (порт, секреты, путь к хранилищу и т.д.).

4. Запустите сборку и сервер:
	```bash
	npm run build
	npm start
	```
Запуск в режиме разработки
	```bash
	npm run dev
	```

5. Откройте браузер по адресу http://localhost:3000 — войдите как первый администратор (пароль задаётся через CLI).

Подробная инструкция по установке, настройке coturn (для видеозвонков) и развёртыванию с nginx/PM2 описана в install.md.

### 📚 Документация
 - install.md — полное руководство по установке и настройке.

 - changelog.md — история изменений.

 - agent.md — правила для ассистента (AI-агента) при работе с кодом.

 - Внутри packages/* — README с API каждого модуля.
